# 链接与关键内容工作流

用户已批准实施：云端后端；保存链接与关键内容，不建设原文归档；官网每天两次监控。

- 同账号规范化链接复用。通知重要字段修改保留有限版本，并提示关联事务重新核对；不自动改个人提醒。
- 结构化待确认项（问题/答案），详情可逐项处理。
- 提醒支持知晓与有限周期再次提醒；系统送达不等于知晓。已完成/取消停止投递。
- Agent 写操作保存前后快照，可预览并逐条撤销；后续版本变化则拒绝覆盖。历史无快照回执不允许撤销。
- 个人数据导出/恢复，不覆盖现有数据；服务器 SQLite 提供一致性备份脚本。
- 北邮官网通知监控：每天09:00和18:00（北京时间），初次建立基线，后续记录新增/变化；失败独立记录，不清空基线。
- 少量关键检查验证冲突保护与数据安全；构建并更新运行版本。
