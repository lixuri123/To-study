# 第四、五步：轻量录入与 Windows 提醒

用户已批准实施，并选择 Windows 系统通知、关闭窗口后托盘驻留。

- [x] 快速收集仅内容/附件，标题自动生成；保存失败保留内容。
- [x] 默认只读详情：状态、下一步、时间、笔记、原文；编辑全部信息按需展开。
- [x] 完成、稍后提醒、只收藏、转事务可直接操作；MCP 修改自动刷新且不覆盖本地草稿。
- [x] 后端提醒投递记录：按账号、设备、提醒内容去重；租约领取、发送结果、退避重试和重启补偿。
- [x] Tauri 托盘、系统通知、原生周期检查；关闭窗口隐藏，托盘退出保留草稿确认。
- [x] 打包 Windows 安装程序并提供验收步骤；运行少量关键检查。

系统接受通知不代表用户已阅读；Windows 勿扰可能抑制横幅。关机不运行提醒，恢复后补查。保持现有 API 和数据兼容，不在本次增加邮件或网站监控。
