# Notes and Tasks MVP Implementation Plan

**Goal:** 可运行的中文 Web 记事本与待办，支持账号隔离和持久化。

**Architecture:** React 调用 FastAPI，服务端 SQLAlchemy 数据模型由 Alembic 迁移。PostgreSQL 为部署目标；本地默认 SQLite 作为无需额外服务的开发适配，非多端架构变更。随机会话令牌服务端仅保存哈希，7 天过期，退出即撤销。

**Tech Stack:** React / TypeScript / Vite / Tailwind / shadcn 风格源码组件；FastAPI / SQLAlchemy / Alembic / pwdlib / uv / pytest。

## Scope

- 注册登录，用户名 3–40 位、密码 8–128 位；每个资源按当前用户过滤。
- 笔记列表、搜索、创建、显式保存、删除及未保存离开确认。
- 待办创建、完成切换、筛选和删除。
- 空标题拒绝，错误可见，请求期间阻止重复提交。
- 本轮不制作桌面/移动外壳、离线同步或公开部署。

## Execution

- [ ] 后端：tests/test_api.py 先验证 CRUD、身份隔离、鉴权、持久化；backend/models.py 定义模型，backend/security.py 管理会话，backend/main.py 暴露 API，backend/schemas.py 校验输入。运行 uv run pytest。
- [ ] 数据库：alembic/env.py 和 versions/0001_initial.py 建立可升级/降级表结构，DATABASE_URL 选择数据库。执行 uv run alembic upgrade head。
- [ ] 前端：frontend/src 中隔离 API、界面和基础组件；Vitest 验证交互；npm run build 执行类型与生产构建检查。由前端子代理独立实现。
- [ ] 集成：main.py 启动本机服务，服务构建后的前端；README 写明开发、打包、PostgreSQL 与限制。运行 API 测试、前端测试和实际 HTTP 冒烟检查。

## API contract

POST /api/auth/register, /login: {username,password} -> {token,username}; GET /api/auth/me -> {username}; POST /api/auth/logout. Bearer token.

GET/POST /api/notes; PUT/DELETE /api/notes/{id}. Note: {id,title,content,updated_at}.

GET/POST /api/tasks; PATCH/DELETE /api/tasks/{id}. Task: {id,title,completed,created_at}.

所有集合返回数组，失败返回 detail，缺失或跨账号资源返回 404。
