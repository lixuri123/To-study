# 按周课表

用户已确认：独立课表页，粘贴学校课程表后预览、勾选导入，支持手动增删改。

按周一至周日、1–14 节展示，支持最多 53 周。可浏览范围为第 1 周至学期总周数或课程最大结束周中的较大值。学期设置保存第一周周一日期和总周数（默认 20）；未设置日期时仍可按周浏览，不猜测开学日期。设置后按设备本地日期计算当前教学周，学期外明确说明。

每门课程保留课程号、课程名、班级、校区。安排由星期、起止节次、起止周、全部/单/双周、教师、地点构成。一课可有多条安排，分段地点/教师变更保留各自周次。只显示所选周实际发生的安排；冲突课同时可见并提示，不能覆盖。不同班级不合并。

导入在服务器解析但不保存，返回逐行预览和错误。错误行保留原文以便修正；仅用户勾选的课程批量保存，一次事务提交；相同课程完整内容重复导入跳过。手动编辑所有安排，支持添加与删除安排。课程资料按账号隔离。

后端采用现有 FastAPI/SQLAlchemy/Pydantic 模式，新增 timetable 模块和 0005 迁移。使用 JSON 保存经结构校验的课程安排；更新使用版本检查避免覆盖其他设备修改。前端沿用纸色和绿色设计，桌面周网格、窄屏可横向滚动，编辑面板拥有表单校验和保存失败保留内容，编辑期间阻止切换与关闭丢失草稿。

验证：用户 46 行样例；起止周包含性、双周、单周换教师、分段地点、一周两次；API 身份隔离、校验、批量导入、更新冲突、删除；组件交互、按周可见性、保存失败；旧功能回归及生产构建。
