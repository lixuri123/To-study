# 待办时间段与提醒

入口在「待办清单」原有的截止日期位置，新建和已有待办均可使用。默认选择「单日」；切换「时间段」后选择区间起始、结束日期，再点击确定。列表显示完整区间，在其中任一天都可以完成，只有区间结束且未完成才算逾期。切回单日会清除区间起始日期。

时钟按钮仅用于已有的提醒和准备笔记设置，不再提供第二个日期编辑入口。日期字段复用start_date与due_date，不新增数据库字段或重复执行机制。选择区间本身不会自动开启提醒。

勾选完成或删除待办后停止后续提醒。知晓某一天的提醒不影响后续日期；日期修改后未触发提醒同步调整，自定义稍后提醒保留。准备笔记可以在同一面板关联。

计划日历显示待办区间条；点击打开待办列表并滚动到对应记录。区间不生成多个待办，也不生成打卡。原待办的标题、截止日期、勾选和删除入口保留。

新增迁移0011只为tasks增加可选开始日期和JSON提醒/笔记字段，旧待办不自动设置提醒。Windows提醒复用现有投递机制，网页版提供应用内提醒。原事务区间数据保留兼容，但新功能的入口是待办。
