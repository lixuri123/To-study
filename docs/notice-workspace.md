# 通知整理验收

刷新青笺，打开原通知，查看通知整理概览：关联事务和完成数、当前提醒、待确认时间、去重准备笔记。点击事务可进入，点击“原通知”返回。

展开“Agent 整理回执”查看该通知、子事务与关联笔记的成功写入历史，支持加载更早记录。它不是整组成功证明；当前提醒来自实时事务，不读取笔记中的过期描述。

展开“采集状态”：旧数据默认完整性未核验。Agent 可通过新增 MCP 工具 record_capture_attempt 记录实际结果、错误类别、缺失项和最近20次历史。失败保留原文；恢复更新原记录，不创建重复通知。新工具需要重新加载 MCP 连接后使用。

“继续采集 / 交给 Agent”展示可复制的指令。复制给 Codex 后，由 Agent 实际读取来源、处理缺失内容，再写回结果。该入口不会自行启动浏览器、后台抓取或公众号监控；验证页需用户处理。无法复制时可手动选取指令。

网页版和原有 Windows 0.2.0 桌面版均从后端获取新版页面，无需更换桌面安装包。后端需重启加载新接口。
