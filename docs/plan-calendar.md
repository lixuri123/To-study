# 计划日历与打卡（第一阶段）

入口为 Web 端的「计划与目标」。默认进入周日历，可切换月日历；原目标规则、清单和进展记录保留在「目标档案」。

## 已实现范围

- 新建、编辑、归档和恢复计划；支持指定一天、固定星期、每周若干次。
- 设置开始和结束日期，每次目标数量与单位，可选关联目标。
- 在当天或过去日期记录完成、部分完成、跳过；支持备注、关联笔记、编辑与撤销。同一计划每天一条记录。
- 弹性计划显示本周完成次数；只有「完成」计入次数，「部分完成」与「跳过」保留实际记录。
- 原待办清单按截止日期显示在日历与当天安排中，可以直接勾选；待办完成不生成打卡。
- 计划、打卡、原目标及关联笔记纳入账号备份，恢复新增记录并重新映射关联；兼容不含新字段的旧备份。

目标表示达成规则，计划表示未来安排，打卡表示实际发生。第一阶段不自动把打卡折算为原目标进展。

## 启动与验收

后端启动会执行新增迁移 `0010`，创建 `plans` 与 `plan_checkins`，不重建旧目标表。重启后端并刷新 Web 页面后进入「计划与目标」。

建议手动验收：创建每周三次的计划，今天完成并补记一个过去日期，编辑数量与备注，撤销一次记录；切换月视图；为待办设置截止日期并在日历中勾选；查看原目标档案。新表单编辑或保存时暂时限制切换，取消后恢复。

课表叠加、周复盘、计划提醒与 MCP 计划工具属于后续阶段，本次不扩展。
