# 青笺 0.2.0 验收

## 启动

1. 在项目根目录执行 `.venv/Scripts/python.exe main.py`，保持后端运行。启动会自动执行数据库迁移。
2. 安装 `desktop/src-tauri/target/release/bundle/nsis/青笺_0.2.0_x64-setup.exe`，打开青笺，连接 `http://127.0.0.1:8000`，登录原有账号。
3. 如旧版正在运行，先退出旧版再安装。系统通知请使用安装后的桌面版验收。

## 第四步：轻量记录

1. 快速记录中直接粘贴一段通知，点击“收下”。无需手填标题或日期；标题从首行生成。可单独收下附件。
2. 保存后默认显示详情，核对原文；点击“编辑全部信息”时才展开完整表单。
3. 将信息设为“需要办理”，填写时间并关联已有笔记；返回详情，打开笔记，尝试“明天提醒我”和“标记完成”。
4. 通过 MCP 修改记录后，等待约 15 秒或切回窗口，核对内容和最近修改者。编辑中的未保存内容应保留。

## 第五步：托盘提醒

1. 在 Windows 托盘中右键青笺，选择“发送测试通知”，确认通知横幅或通知中心有记录。
2. 创建未完成事务，在完整编辑中设置一条约两分钟后的自定义提醒，保存。
3. 点击窗口右上角关闭按钮，确认青笺仍在托盘。到时应收到通知（通常有约 15 秒检查间隔）。
4. 从托盘打开青笺，完成事务。系统接收通知本身不会替你完成事务。
5. 已发送的同一提醒正常情况下不会重复；改变提醒时间可再次提醒。断开后端再恢复，会自动重试。退出青笺后错过的未完成提醒会在重新登录运行时补查。
6. 从托盘选择“退出青笺（停止提醒）”才真正退出；有未保存草稿时应出现原有确认流程。

## 运行条件

后端服务、已登录桌面版和电脑都必须保持运行。仅关闭窗口会隐藏到托盘；注销、退出应用、休眠和关机期间无法发送。Windows 勿扰或系统通知设置可能抑制横幅。当前不自动配置开机启动。

后端记录发送租约及回执，失败退避重试；系统接受不代表用户阅读。极少数“系统已接收，但回执前程序崩溃”的情况可能重复发送，不保证严格只发一次。

本轮以构建与少量关键检查为基线；真实 Windows 通知显示及日常操作体验由本次验收确认。
