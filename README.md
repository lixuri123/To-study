# 记事本与待办应用

面向 Web、桌面、Android 和 iOS 的笔记与待办项目。

技术选型与开发顺序见 [技术选型文档](docs/technology-stack.md)。

## 本地运行

1. 在根目录执行 `uv sync`。
2. 在 `frontend` 执行 `npm install` 和 `npm run build`。
3. 回到根目录执行 `uv run python main.py`，访问 `http://127.0.0.1:8000`。

入口会先执行数据库迁移，保留现有账号、笔记和待办。开发前端时，可在 `frontend` 单独执行 `npm run dev`，通过 Vite 代理访问 `/api`。

## Docker 部署

仓库提供多阶段 `Dockerfile` 和 `compose.yaml`，一个容器同时提供 Web 页面与 FastAPI 接口。服务器部署、现有 SQLite 数据迁移、HTTPS 配置、更新和恢复步骤见 [Docker 部署文档](docs/docker-deployment.md)。数据库、环境变量和 MCP 本机凭据不会打入镜像或提交 Git。

## 模块

- `backend/auth`：注册、登录、会话撤销、认证与限流。
- `backend/notes`、`backend/tasks`：各自的模型、输入校验、路由和业务。
- `backend/database.py`、`backend/common`：数据库依赖与公共能力。
- `frontend/src/features`：按认证、笔记、待办组织界面和状态；`layouts` 负责工作台布局。

登录行为、部署设置和测试方式见 [登录说明](docs/authentication.md)。

## 笔记与待办

- 笔记正文支持 Markdown 编辑、预览和分屏，提供格式速查。支持标题、列表、引用、代码块、表格和只读任务列表；窄屏分屏上下排列。保存原始 Markdown，保留普通文本换行，原始 HTML 不会执行。
- 笔记支持 Ctrl/Cmd+S、保存失败重试、保存后继续/放弃/继续编辑三种离开选项，以及窄屏列表和编辑切换。
- 待办点击标题即可修改（Enter 保存，Esc 取消），支持设置或清除截止日期，以及今天、已逾期筛选。
- 待办按未完成优先、截止日期从近到远排列；单条操作期间其他待办仍可使用。
- 启动时自动应用 `0003` 迁移，为旧待办添加可空截止日期，保留已有数据。

## 信息与事务（第一阶段）

现已提供本地 MCP 工具，供 Codex 查询和写入青笺。安装、账号授权、撤销与工作流说明见 [MCP 接入文档](docs/mcp.md)，术语见 [CONTEXT.md](CONTEXT.md)。提醒仍为应用内提醒。

侧边栏新增“信息与事务”。支持快速粘贴通知原文、记录摘要和来源，上传 PNG/JPEG/PDF/文本附件（最多 3 个、每个 2 MB），之后再补充时间。信息收藏可以转为需要办理的事务；原有快速待办继续可用。

- 分开保存通知发布时间、开始时间、截止时间、录入时间；可只填日期，或选择具体时刻，也可标记时间待确认。
- 支持待整理、已整理、即将开始、正在办理、即将截止（3 天内）、逾期和完成筛选。办理状态与时间阶段分别记录。
- 可关联多篇已有笔记或新建准备笔记；笔记页面显示反向关联，也可以从笔记创建事务。取消关联不会删除笔记。
- 自定义提醒，以及开始时、提前一天准备、截止前一天/一小时的相对提醒。修改时间后相对提醒自动调整；仅日期按当前设备当地零点开始、23:59 截止计算提醒。
- 到期提醒在工作台显示，可确认、一小时后再提醒或完成事务。提醒保存在服务器，重新打开后会显示未确认的过期提醒。**本阶段为应用内提醒，应用关闭时不发送系统推送或邮件。**
- 支持完成标准、办理凭证文本/链接、时间修改历史和并发版本检查。未保存的事务会阻止页面切换，保存失败可继续编辑并重试。

重启 `uv run python main.py` 会自动应用 `0004` 迁移，保留原账号、笔记和待办。信息监控属于第二阶段，尚未接入。

## 按周课表

侧边栏「我的课表」按周一至周日、1–14 节展示课程。通过「学期设置」填写**第一周周一的日期**和学期周数后，可自动定位当前教学周；未设置日期也可按周次浏览。

- 粘贴教务系统复制的制表符分隔课程文本，先解析预览，再勾选自己的课程和班级导入。无法识别的行显示原文和行号，修正后可重新解析；重复导入完全相同的课程会跳过。
- 支持起止周（含首尾）、单周/双周、单独一周、一周多次上课，以及按周次更换教师和教室。周视图只显示该周实际发生的课程。
- 可手动添加、编辑和删除课程；一门课可添加多条安排。完整课程列表也能编辑当前周没有开课的课程。重叠课程同时显示并标记冲突。
- 数据随账号保存；编辑或保存过程中会保护草稿，保存失败可重试。

重启 `uv run python main.py` 会自动应用 `0005` 迁移，保留已有账号、笔记、待办和事务。更新前端后需在 `frontend` 执行 `npm run build`。

## 通用目标与进展

“我的目标”可以把清单条件和计数条件组合在同一个目标中；全部条件满足时才显示“已达成”，不使用总进度百分比。进度记录表示已经完成的事实，与待办和事务分别保存。

内置的全日制研究生综合素质模板实现来源文件中的两项汇总规则，同时允许自行填写活动名称，不受建议名称限制。重启 `uv run python main.py` 会应用 `0009` 迁移并保留现有数据。

## Windows 桌面版使用

`desktop` 目录提供 Tauri Windows 客户端，连接现有服务，共享账号和数据。首次打开填写服务地址；本机开发可填写 `http://127.0.0.1:8000`。详见 [桌面使用与构建说明](docs/desktop.md)。
